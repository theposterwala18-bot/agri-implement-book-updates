# Agri Implement Booking Updates

Official Windows client update packages from Mr Dhaliwal Creation.

Use Check Update inside Agri v1.8.2 or later. Save your current entry before installing. Updates replace only the program; booking data and activation remain unchanged.

For older clients, run the latest Setup EXE once. Future Check Update downloads and starts the installer.

This repository contains public client update packages only. It does not contain society data, owner tools, private keys or subscription records.
